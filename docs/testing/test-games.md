# Testspiele (Stand 18.11.2026)

Status ist für alle Titel: **nicht getestet**. Einträge werden mit Datum, Hardware, Proton-Version und Ergebnis ergänzt.

| Spiel | Anti-Cheat / Besonderheit | Erwartung nach Recherche | Teststatus |
|---|---|---|---|
| Microsoft Flight Simulator 2024 (Steam-Version) | Kein klassisches Anti-Cheat bekannt. Nur die Steam-Version ist unter Linux praktikabel (Store/Game Pass nicht). | Läuft laut Forenberichten oft per Proton, mit Einzelproblemen (z. B. Startvideo auf Bazzite, Steuergeräte brauchen teils Startoptionen, VR unzuverlässig). | nicht getestet |
| MSFS Add-ons | Add-ons mit eigenem Windows-Installer unklar | offen, Liste von Mike erwartet | nicht getestet |
| Medieval Dynasty | noch nicht recherchiert | offen | nicht getestet |
| Rust | Easy Anti-Cheat, vom Hersteller für Proton/Linux nicht freigegeben | läuft nicht auf offiziellen Servern | nicht getestet |
| Battlefield | EA Javelin (Kernel-Anti-Cheat) | unter Linux nicht lauffähig | nicht getestet |

Steuergeräte-Test: Thrustmaster Airbus Sidestick, Schubregler, Velocity-Pedale (Erkennung, Achsen, Tasten, ggf. Proton-Startoption für HID-Zugriff).
Spielergebnisse auf Laufwerk E: (Festplatte) sind als "Leistung nicht aussagekräftig" zu kennzeichnen (ADR 0005).
Mehr Spiele werden ab Phase 3 zu einer Liste von 20–30 Referenzspielen erweitert (DirectX 9, 10, 11, 12, Vulkan, OpenGL, mit EAC und BattlEye).
